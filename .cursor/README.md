# Cursor

1. Copy [`mcp.json.example`](mcp.json.example) → `mcp.json` (or run `pnpm generate:mcp-configs --local` from repo root).
2. Set `BLEKLINE_WORKSPACE_TOKEN` and `BLEKLINE_API_URL` in your environment or Cursor MCP env block.
3. Reload the Cursor window — check **Settings → MCP** for `blekline` and `blekline-proxy`.

`BLEKLINE_CLIENT_SURFACE=cursor`

Docs: [Cursor MCP](https://app.blekline.com/docs/mcp/cursor)
