# Blocked prompt

When Blekline blocks Send:

1. Tell the user native Cursor chat **cannot** silently auto-send a rewritten prompt.
2. A masked copy is on the clipboard when copy succeeded — paste (Cmd+V / Ctrl+V) then Enter.
3. Never reconstruct the original secrets from memory or logs.

For zero-click masking, use Blekline ingress on agents the team controls — not native Cursor chat.
