# Plugin assets

| File | Use |
|------|-----|
| `logo.svg` | Cursor plugin + MCP listing icon (from `webapp/public/branding/blekline-icon.svg`) |
| `logo.png` | Optional square webclip for marketplace screenshots |

```bash
cp webapp/public/branding/blekline-icon.svg plugins/cursor/assets/logo.svg
cp webapp/public/branding/blekline_webclip.png plugins/cursor/assets/logo.png  # optional
```
