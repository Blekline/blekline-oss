# Claude Desktop

Claude Desktop reads MCP config from an OS-specific path — not a repo dotdir.

1. Copy [`claude_desktop_config.json.example`](claude_desktop_config.json.example).
2. Merge the `mcpServers` block into your Claude Desktop config file.
3. Restart Claude Desktop.

`BLEKLINE_CLIENT_SURFACE=claude-desktop`

Docs: [Claude Desktop MCP](https://app.blekline.com/docs/mcp/claude-desktop)
